Frequently asked questions

Short answers to what people ask most often.

What is Crypto Polymath?

It is a crypto market analytics platform. It collects prices, historical candlesticks and technical indicators from six major exchanges and normalises them into a single format, alongside trader calculators — from average entry price to liquidation price.

Which exchanges are supported?

Binance, Bybit, OKX, Kraken, KuCoin and Gate.io. Data from every exchange is normalised to the same shape, so prices and candlesticks from different venues can be compared directly.

Do I need to sign up?

No. No account, no exchange API keys and no installation: just open the tools page in your browser and pick an exchange and a coin.

Which technical indicators can I calculate?

Moving averages, RSI, MACD, stochastic and trend metrics, plus Heiken Ashi smoothed candlesticks. The lookback depth is chosen from the values each indicator supports.

What do the trader calculators compute?

Average entry price when averaging by volume or by margin amount, position size from margin and leverage, liquidation price of an isolated position, distance to liquidation in percent, unrealized PnL and spot PnL, and a full risk snapshot at a given market price.

Can I get this data programmatically?

Yes, everything is available through a REST API with a single contract: the same request works for any supported exchange. All methods are described in the API documentation.
