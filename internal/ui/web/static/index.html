Как это работает

Без интеграции — чтобы оценить данные, достаточно браузера.

1
Выберите функцию

В меню сверху — по бирже, символу, индикатору или калькулятору.

2
Заполните параметры

Списки бирж, монет, индикаторов и их параметров подгружаются из API.

3
Получите результат

Ответ API отображается сразу во всплывающем окне.
